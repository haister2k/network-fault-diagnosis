Network Connectivity: Interactive Fault Diagnosis

Interactive network administration training

Scenario

An organization is migrating application servers to a new subnet. A load balancer distributes requests between the original and migrated application servers. Users report intermittent failures when the application accesses its database.

The application servers are running and the database service is available. Examine the network configuration to determine why some database connections fail.

Learning objective: Identify the network configuration fault, select an appropriately restricted correction, and verify that authorized communication succeeds while access from unrelated networks remains blocked.

1. Inspect the Network

Select a device in the 3D view or use the buttons below it to examine its configuration and diagnostic information.

Select a device to display diagnostic information.

2. Select a Corrective Action

Review the evidence before choosing how to modify the firewall policy.

Proposed firewall correction
Choose a correction and run the verification checks.

3. Review the Results

A successful correction must restore database access for the migrated application servers while preventing unrelated networks from reaching the database.

This exercise uses predefined network conditions to evaluate troubleshooting decisions. It does not make changes to real network equipment.

Graphics Compatibility Check

Before the network troubleshooting activity opens, this page tests whether the browser can render a 3D WebGL image. A working WebGL renderer is required for the network view.

Browsers may conceal graphics device information. WebGL rendering can succeed without confirming hardware acceleration. The test blocks a renderer explicitly identified as software.

If the test fails

In Firefox, enter about:support in a new tab and check the Graphics section. You can review acceleration settings under Settings → General → Performance. A browser restart may be necessary after changing settings. Then return here and select Run check again.

No system settings are changed by this page. No graphics information is sent to a server.

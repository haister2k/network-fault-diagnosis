Browsers may conceal graphics device information. WebGL rendering can succeed without confirming hardware acceleration. The test blocks a renderer explicitly identified as software.

If the graphics check fails

Choose your browser for steps to review graphics acceleration. After changing a browser setting, restart that browser, return to this page, and select Run check again. If the result seems inconsistent with your browser graphics report, choose Reload latest version to request a fresh copy of this page.

Microsoft Edge
  1. Open a new tab and enter edge://settings/system in the address bar.
  2. Turn on Use graphics acceleration when available.
  3. Select Restart if prompted, or close and reopen Edge.
  4. For a detailed status check, enter edge://gpu and review Graphics Feature Status, especially WebGL.
  5. Return to this page and select Run check again.
Google Chrome
  1. Open a new tab and enter chrome://settings/system in the address bar.
  2. Turn on Use graphics acceleration when available.
  3. Select Relaunch if prompted, or close and reopen Chrome.
  4. For a detailed status check, enter chrome://gpu and review Graphics Feature Status, especially WebGL.
  5. Return to this page and select Run check again.
Mozilla Firefox
  1. Open Firefox Settings. Under General or Tabs and browsing, locate Performance.
  2. If the acceleration setting is hidden, clear Use recommended performance settings.
  3. Check Use hardware acceleration when available, if the option appears.
  4. Close and reopen Firefox. For details, enter about:support and inspect the Graphics section.
  5. Return to this page and select Run check again.

If WebGL still fails, the browser, graphics driver, or device policy may be limiting graphics acceleration. Do not change advanced browser flags to bypass compatibility restrictions. This page does not alter browser settings or send graphics information to a server.
